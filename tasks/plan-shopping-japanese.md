# 팀장 브리프 — 쇼핑쇼츠(상품·여행) + 일본어판(전 형식) 추가

> 기획 개정용 팀장 문서(목차·결정·미결). 본문은 각 docs 장에 쓴다. 근거: `docs/research/shopping-shorts-notion-analysis.md`(노션 강의 텍스트 전부 + 이미지 49/약 200장 + 웹 보강), 예능형·카테고리형 브리프(`plan-variety-shorts.md`·`plan-category-shorts.md`)의 공통 결정(로컬 워커·서명 URL·Claude 키는 API에만·업로드 기본·권리 확인)은 그대로 적용한다.

## 큰 틀 (사용자 정의 2026-11-19)
| 축 | 값 |
|---|---|
| 유형 `kind` | `general` 일반쇼츠 = 조회수 수익 / `shopping` 쇼핑쇼츠 = 제휴 링크 전환 수익 |
| 형식 `format` | general: `category`·`variety`(이후 추가) / shopping: `shopping` |
| 분야 `vertical`(shopping만) | `product` 상품(쿠팡·라쿠텐·아마존 등) / `travel` 여행(트립닷컴·여기어때·마이리얼트립·네이버 여행 등) |
| 언어 `lang` | `ko`·`ja` — 모든 유형·형식 공통. 일본쇼츠는 형식이 아니라 각 콘텐츠의 일본어판 |
- 링밥은 상품·제휴처가 아니다. 제작 도구(AI)이며 Nomadroom에 연동하지 않는다. 링크 페이지는 인포크링크(운영자가 직접 관리)다.

## 확정 결정 (사용자 2026-11-19)
| ID | 결정 |
|---|---|
| D-S1 | 쇼핑쇼츠는 일반쇼츠와 구성 자체가 다르다. 목적은 설득 → 행동 유도(댓글 → DM → 링크)다 |
| D-S2 | 여행은 쇼핑쇼츠에 들어간다(제휴 수익) |
| D-S3 | 원본은 샤오홍슈 등에서 받은 영상 3~5개 이상을 짜깁기한다(여행은 운영자 촬영이나 외부 AI 생성 영상도 가능) |
| D-S4 | 저작권·초상권(사진·영상·음원·글꼴)을 기획에 포함한다 |
| D-J1 | 일본어판은 카테고리형·예능형·쇼핑 모두에 적용한다. 구어체 번역 + 일본어 TTS + 일본어 자막을 쓴다 |
| D-J2 | 예능형 일본어판은 **일본어 TTS 더빙**이다 |
| D-J3 | 번역은 Claude 초안 + 사람 수정이다 |

## 팀장 설계 결정
- **원본 확보**: 운영자가 파일을 업로드한다. 샤오홍슈·제휴처 사이트 자동 수집·다운로드는 하지 않는다(로그인 필요, 공식 API 없음, 우회 금지 원칙). "3개 이상이면 저작권 위험이 줄어든다"는 강의 주장이고 법적 근거가 아니다(근거 문서 #12). 원본 수가 3 미만이면 경고만 한다.
- **권리 기록(모든 형식의 원본 자산에 확장, 쇼핑은 필수)**: 자산마다 `rights{basis: own·licensed·permission·quote·platform_audio·ai_generated(P1), source_url, author, has_person, portrait_consent, note}`를 둔다. 쇼핑은 모든 원본·이미지·BGM의 basis가 정해지고, `has_person=true`이면 `portrait_consent=true`여야 승인된다. 리포트에 출처·권리 목록을 넣는다. 일반쇼츠는 기존 작업 단위 `rights_confirmed`를 유지하고, 자산 단위 기록은 선택이다.
- **쇼핑 입력(작업)**
  - `brief`: 상품이면 제품명·해결하는 불편 1개·영상에 실제로 나오는 장면 3~5·빼야 할 말·확인된 사실(가격·효능·수치). 여행이면 목적지·상품 종류(숙소·투어·패키지)·소구점 1개·장면 3~5·확인된 사실.
  - 그 밖에 `target`(성별·연령대, 메모용), `affiliates[]{lang, partner, url}`(운영자가 발급한 링크를 수동 입력), `comment_keyword`(댓글 유도 단어).
- **금지 품목**: 의약품·건강기능식품이다. 작업 생성 때 분야 체크박스와 키워드 검사로 막는다. 과장·효능 표현은 대본 검증(금지어 목록)으로 막는다.
- **쇼핑 spec (`format=shopping`, 1080×1920, 15~20초 기준)**
  - `script[4]{text}`: 정확히 4문장, 공백 포함 합계 110~140자. 범위를 벗어나면 경고, 문장이 4개가 아니면 오류. `[확인 필요]`가 남아 있으면 오류. 금지 문구("강력 추천"·"인생템"·"지금 바로" 등)는 경고. 1번 문장에 제품명이 있으면 경고.
  - `cuts[]{source_asset_id, src_start, src_end, scale, x, y, sentence(1~4), masks[]{x,y,w,h}}`: 원본 여러 개를 쓴다. 컷마다 문장 번호에 묶인다. `masks`는 원본의 외국어 자막을 가리는 블러 영역이다(강의 "중국어 자막 삭제·모자이크"). 문장마다 컷이 1개 이상 있어야 한다. 빈 화면 규칙은 예능형과 같다.
  - `voice`: `tts{voice, rate}` 또는 `narration_asset_id`(첨부 녹음). 둘 중 하나는 필수.
  - `source_audio`: `mute`(기본) 또는 `duck`. `bgm_asset_id?`는 권리 basis가 필수다.
  - 자막은 대본 문장을 렌더러가 TTS 실측 길이에 맞춰 자동 배치한다(문장 → 구간). 컷 길이 합계는 문장 길이에 맞춰 렌더러가 늘이거나 줄인다(마지막 컷을 자르거나 정지 프레임으로 채우고, 리포트에 기록).
  - `cta.text`: 4번 문장 화면 문구. `disclosure.text`: 언어별 기본값(ko "제휴 링크 포함", ja "PR"). 화면 위치는 고정이다.
  - 출력 산출물: MP4 + 리포트 + **게시 문구**(설명란·고정 댓글. 첫 줄은 대가성 표기, 댓글 키워드 안내, 업로드 권장 시각 메모: 인스타 오전 8시·옵션 18시는 강의 기준).
- **AI 대본(P1)**: 노션 프롬프트 규칙을 그대로 쓴다. 입력은 brief + 시트 저해상도, 출력은 후킹이 서로 다른 대본 3안(글자 수·후킹 유형·확인할 사실 목록)이다. 운영자가 하나를 골라 고친다. 같은 소재 대본을 그대로 베끼지 않는다(어문 저작권).
- **일본어판(모든 형식)**
  - 승인된 ko 리비전에서 `lang=ja` 리비전을 파생한다(`edit_revisions.lang`, `derived_from`). 컷·구도·마스크는 ko 값을 고정해 복사하고 텍스트만 바꾼다. ko 리비전이 바뀌면 ja는 "원본 변경됨" 경고와 함께 재파생을 권한다.
  - 번역 API(A-20): Claude가 구어체 일본어 초안을 쓰고 사람이 고친다. 입력은 ko 텍스트만이다.
  - 형식별 음성
    - 카테고리형: 훅 TTS를 일본어 음성으로 바꾼다.
    - 쇼핑: 내레이션 전체를 일본어 TTS로 바꾸고, 자막을 자동 배치한다.
    - 예능형: 대사 자막마다 일본어 TTS를 만들고 원본 소리는 duck(가정 15%)한다. TTS가 자막 구간을 넘으면 rate를 올리고(상한 가정 +30%), 그래도 넘으면 `dub_overflow` 경고를 띄워 검수에서 확인한다.
  - 글꼴: Noto Sans CJK JP Bold(OFL). 제휴·표기는 ja 값(라쿠텐·아마존, "PR")을 쓴다.
  - 렌더 멱등 키는 (작업, 리비전, 언어)이다. 기존 규칙과 같고, 리비전이 언어별로 따로 있다.
- **TTS 의존**: 쇼핑 P0과 모든 일본어판은 TTS가 필수 경로다. edge-tts 라이선스(Q6)를 task-030에서 먼저 확인한다. 불가하면 첨부 녹음으로 대체하고, 대체 TTS 선정은 새 Q로 둔다. 무음·가짜 음성은 금지다.
- **게시**: 유튜브·인스타 자동 업로드, DM 자동 응답, 제휴 링크 자동 발급은 하지 않는다. 게시 문구 복사와 권장 시각 표시까지만 한다.
- **화면**
  - "내부 제작"을 누르면 유형(일반·쇼핑)을 먼저 고른다. 일반이면 형식, 쇼핑이면 분야(상품·여행)를 고른다. PROD-00 목록에 유형·형식·언어 필터를 둔다.
  - PROD-01S: 원본 여러 개 업로드(원본마다 권리 입력) + brief + 제휴 링크 + 금지 품목 경고 + "원본 3개 미만" 경고.
  - PROD-02S: 대본 4문장(글자 수 카운터·금지어·확인 필요 표시, P1 AI 3안) → 문장별 컷 배치(원본 선택·마스크) → 음성(TTS/첨부)·원본 소리 → CTA·표기.
  - PROD-03: 게시 문구 복사, 언어 탭(ko·ja), 권리 목록.
  - 모든 편집 화면에 언어 탭을 두고, ja는 "일본어판 만들기"(파생) → 번역 초안 → 수정 순으로 진행한다.

## 상품 vs 여행 (노션 실습3·"쇼핑과 여행의 차이점" 22장 전부 읽음, 근거 `research/shopping-shorts-notion-analysis.md#7`)
| | 상품 | 여행 |
|---|---|---|
| 같은 것(본질) | 타깃, 카테고리, 설득(소구점 1개), 행동 유도(CTA, 댓글) | 같음 |
| 무엇을 파나 | 물건 | 경험·장소(숙소·투어·패키지). 단가가 크고 1건만 팔려도 이득 |
| 느낌 | 광고로 느껴진다 → 1인칭 후기 말투로 방어심리를 낮춘다 | **광고가 아니라 설렘**. "정보 찾기 귀찮음 → 대신 추천 → 좋은 곳 발견" |
| 영상 소스 | 남의 영상 짜깁기(샤오홍슈 등) | **사진(공식 사진만) → AI 영상 생성** + 대본·TTS·편집 |
| 반응 | 구매 클릭 | 저장·공유가 많다(정보형) |
| 제휴처 | 쿠팡(인포크링크), 라쿠텐, 아마존 | 여기어때(팔로워 5천명+심사), 마이리얼트립, 트립닷컴, 네이버 여행(조건 미확인), 쿠팡 |
- 여행 대본(가정, 강의 "3패턴"은 미확인): 같은 4문장 틀을 설렘 서사로 쓴다. ① 후킹(설렘·궁금증, 장소명은 숨김) ② 찾기 귀찮았던 고민 ③ 그곳에서의 장면(사진·영상에 있는 것만) ④ 댓글 유도. brief는 목적지, 상품 종류, 소구점 1개, 장면 3~5, 확인된 사실이다.
- 여행 소스: `image` 자산(공식 사진)과 `source_upload`(운영자가 외부 AI 도구로 만든 영상)를 모두 컷으로 쓸 수 있다. **사진 컷에는 확대·이동 모션(pan/zoom)을 렌더러가 기본 제공한다.** AI 영상 없이도 사진만으로 만들 수 있게 하는 것이 비용 대안이다.
- 사진 권리: 공식 사진(제휴처·숙소 제공)만 쓴다. 남의 사진·블로그 사진은 금지(basis 필수).

## 여행 영상 생성과 비용 (사용자 2026-11-19)
- 여행 쇼핑쇼츠는 영상을 **생성**해야 한다(노션 실습3). 근거 분석은 `docs/research/shopping-shorts-notion-analysis.md#7`.
- **외부 AI 영상 플랫폼을 쓸 수 있다(사용자 정정 2026-11-19).** 구독료·사용료가 클 수 있으므로(사용자 지적) 아래 원칙으로 연동한다.
  - 연동 방식: 공개 API가 있고 상업 이용이 가능한 플랫폼을 FastAPI 서버(키는 API에만)에서 호출한다. 입력은 공식 사진 자산 + 프롬프트, 결과 영상은 `source_upload`(basis `ai_generated`, 플랫폼·모델·요청 ID·비용 기록)로 저장한다. API가 없는 플랫폼은 운영자가 직접 생성해서 업로드한다(같은 basis).
  - 비용 통제: 생성 요청 전에 예상 비용(크레딧·USD)을 보여 주고 확인을 받는다. 작업당 상한과 워크스페이스 월 예산을 넘으면 거부한다. 생성 요청은 멱등 키로 중복 과금을 막는다. 생성 기록(`generation_runs`: 플랫폼·모델·초·비용·상태)을 남겨 제휴 수익과 비교한다.
  - 저비용 대안: 사진 컷 pan/zoom 모션(무료)을 기본으로 두고, AI 생성은 컷별 선택으로 한다.
  - 플랫폼 후보·요금은 근거 문서 #7 "영상 생성 비용"(노션 요금 이미지 + 공식 가격 페이지)이다. 플랫폼 선정, 월 예산, 작업당 상한은 Q16이다. 유료 API 키 발급·사용은 사용자 승인 후에만 한다.
  - 노션 요금 이미지(2026-11, 최고 요금제 월): 그록 $300, 클링 $180, 구글 Flow $199.99, 힉스필드 $375, 소라 $500. 강사 결론은 "퀄리티는 거기서 거기, 가격 보고 편한 것"이며 강사는 그록을 쓴다. AI 결과에는 할루시네이션이 있어 **사람 검수가 필수**다.
  - API 후보(근거 문서 #7-6, 18초 편당 추정, 재생성 미포함): xAI 그록 Imagine Video(1.5 약 $1.44, lite 약 $0.36, 공식 문서), 구글 Veo 3.1(Fast 약 $1.80, Lite 약 $0.90, 제3자 출처), 클링(약 $3.02, 제3자 출처), 힉스필드(API 있음, 단가 미확인). 소라는 API 종료로 제외한다(검색 요약, 공식 재확인).
  - **구독 크레딧과 API 과금은 별개다.** 구독료를 편당 비용에 넣지 않는다. 구독만 있는 경우는 수동 생성 + 업로드로 처리한다.
  - **사용자 판단(2026-11-19): 힉스필드가 가장 비싸지만 품질이 좋다.**
  - 연동 구조: 플랫폼 어댑터 인터페이스 하나에 **품질 등급 2개**를 둔다.
    - `quality`(품질 우선) = 힉스필드. 대표 컷과 후킹 컷에 쓴다.
    - `economy`(비용 우선) = xAI 그록. 나머지 컷과 시안에 쓴다.
    - 컷마다 등급을 고르고, 예상 비용을 등급별로 보여 준다.
    - 첫 구현은 힉스필드 + 그록 두 어댑터다. 최종 확정은 Q16(약관·예산)에서 한다.
    - 상업 이용 약관은 착수 전에 확인한다.
  - 생성 결과는 PROD-02S에서 컷마다 "검수 완료" 체크를 받아야 승인할 수 있다(할루시네이션 대비).
