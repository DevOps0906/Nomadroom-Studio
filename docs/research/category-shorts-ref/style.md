# 카테고리형 화면·자막 규격

소재와 관계없이 적용하는 기본값이며 사용자의 현재 요청을 우선한다.

## 화면 규격


### 해상도·출력
- **608×1080, 30fps**, H.264 (libx264 `-preset slow -crf 18`, yuv420p)
- 오디오 AAC 192k / 48kHz, `+faststart`
- 출력 해상도가 608×1080 이다. 1080×1920 이 아님에 주의.

### 영상 창 위치
- 캔버스 전체가 영상 창이다. 좌우 여백이 없다.
- 상단 **0~280px 는 검정 바**(제목 영역)이고, 원본 영상 위에 덮인다.
- 원본은 608×1080 으로 맞춘 뒤 컷마다 **배율 z** 로 키운다.
  - 가로는 가운데 정렬
  - 세로는 원본 상단을 캔버스 **y=Y** 에 놓는다
- 화면에 보이는 원본 영역(1080 기준) = `(280-Y)/z ~ (1080-Y)/z`
- 화면 아래가 비지 않으려면 `Y + 1080×z ≥ 1080`

### 컷별 배율 규칙 (얼굴 확대 기준 대신 이것을 쓴다)
- **얼굴 확대(줌인) 기능은 없다.** 확대는 컷마다 배율을 번갈아 바꾸는 용도와 원본 라벨을 숨기는 용도로만 쓴다.
- 컷이 바뀔 때마다 배율을 번갈아 쓴다: 1.0 ↔ 1.15 / 1.3
- 원본에 박힌 외국어 라벨은 배율과 Y 로 검정 바 뒤나 화면 밖으로 보낸다.
  - **라벨이 원본 아래쪽에 있을 때** (예: y 909~965): 1.0배 Y=180, 1.3배 Y=20
  - **라벨이 원본 위쪽에 있을 때** (예: y 280~316): 1.0배로는 못 가린다 → 1.15배 Y=-90 ↔ 1.3배 Y=-140
- **얼굴 보존 규칙**: 라벨을 숨기다 얼굴이 잘리는 컷은 아래처럼 한다.
  - 그 컷만 1.0배 Y=280 으로 원본 위쪽부터 보여준다.
  - 그 컷의 \*강조\* 박스를 라벨 위치로 내려 라벨을 덮는다.
  - 박스 y = Y + 라벨y×z (예: 280 + 298×1.0 = 578)

- 가로는 가운데 정렬이다.

### 대사(내레이션) 자막
- 글자 크기는 아래 표의 px 값을 기준으로 한다.
- 가로는 가운데 정렬이다. 넘치면 자동 축소된다.

| 종류 | 위치 (중심 y) | 한국어판 | 일본어판 | 색·모양 | 최대 폭 |
|---|---|---|---|---|---|
| 흰 자막 (기본·훅·엔딩) | 700 | 28px | 22px | 흰색, 검정 외곽선 2px | 560 |
| (괄호) 속마음 | 700 | 34px | 28px | 노랑 #FCCC2C, 검정 외곽선 4px | 560 |
| \*강조\* 공감 반응 | 390 (컷별로 바꿀 수 있음) | 36px | 31px | 네온초록 #04FC04, 검정 둥근 박스(불투명도 235, 반경 12) | 520 |

- 한국어 자막 폰트: Noto Sans CJK KR Bold (배포본 대체 폰트)
- 일본어 자막 폰트: 일본어·영문·숫자 모두 Noto Sans CJK JP Bold (배포본 대체 폰트)
- 별표 `*` 와 괄호 `( )` 는 화면에도 그대로 나온다.

### 댓글·출처
- **이 프리셋에는 댓글 표시와 출처 표기가 없다.** 사용자 요청이나 원본 이용 조건에 필요한 표기는 반영한다.

### 색보정
- 전 컷 공통: `eq=saturation=1.15:contrast=1.08`
- 배포본은 확대 후 Pillow UnsharpMask(radius=2, percent=100, threshold=3)로 선명도를 조정한다.
- 컷별 보정은 없다.

## 자막 문체


- 흰 자막: `~하고 / ~했는데 / ~더니` 로 이어지는 내레이션
- \*강조\*: 짧은 공감 반응
  - 금지: 정보 전달, 분석, 뉴스 톤, 도덕 평가, 억지 감탄
- (괄호): 영상 속 인물의 속마음
- 개수: 15~18초 기준 강조 1개 + 괄호 1~2개
- 같은 컷에 자막 두 개를 동시에 띄우지 않는다.
- 엔딩은 여운으로 `~다고 ..` (일본어 `~って…`)
- 일본어판은 직역하지 않고 일본 감성으로 의역한다 (`ㅋㅋ`→`w`).
  - 일본어는 길어지기 쉬우니 짧게 쓴다 (약 16자).

---


## 적용 주의
자막 크기는 표의 px 값을 우선한다. 라벨 위치와 배율은 예시이며 실제 프레임에 맞게 조정한다. 얼굴뿐 아니라 손, 악기, 동물, 제품 등 핵심 피사체와 동작을 보존한다. 출처·권리자 워터마크는 일반 외국어 자막과 구분한다.
