## 공통 규칙
| 항목 | 내용 |
|---|---|
| 기준 경로·형식 | `/v1/...` JSON. 시각은 ISO 8601 UTC(화면에서 KST 변환). 목록은 `page`·`size`(기본 24, 최대 60 — 가정) |
| 권한 | "로그인" = JWT 서명·만료 검증 + `workspace_members` 소속. 워크스페이스는 JWT로 결정(입력으로 받지 않음) |
| 멱등 | 실행류 POST는 `Idempotency-Key` 헤더 필수(`jobs.idempotency_key`). 같은 키 재요청은 기존 job 반환 |
| 오류 형식 | `{code, message, field?}`. 키·토큰·쿠키·내부 경로는 메시지에 넣지 않는다 |
| 공통 오류 | 400 `VALIDATION`(필드별) · 401 `UNAUTHENTICATED` · 403 `FORBIDDEN`(소속 없음. 타 워크스페이스 리소스는 404) · 404 `NOT_FOUND` · 409 `CONFLICT` · 429 `RATE_LIMITED`·`QUOTA_EXCEEDED` · 405 `METHOD_NOT_ALLOWED` · 500 `INTERNAL` · 502 `UPSTREAM_ERROR`(YouTube) · 503 `UPSTREAM_ERROR`(Supabase 인증 키·DB 조회 실패) |
| 상한(가정) | 실행당 후보 200(`01_PRD.md#7` Q3) · 검증 대상 프로필 최대 3 · YouTube 조회 `videos.list` 50개/호출 · `search.list`는 후보 수집(A-05, `params.source=youtube_search`)에서만 — 단가·일 상한은 `adr/0002-observation-quota.md` 결정(2026-11-17) · 재시도 상한·워커 오프라인 기준은 `02_ARCHITECTURE.md#3-3` |

### 제작 API
카테고리형. 흐름 `02b_PRODUCTION_FLOW.md` · 컬럼 `05_DATA_MODEL.md#제작-테이블`.
공통: 경로·자산은 **ID만** 주고받는다(경로·파일명 입력 없음). 타 워크스페이스·없는 id는 404. 상태가 맞지 않으면 409 `CONFLICT`(`message`에 현재 `status`, 공통 오류 형식 유지). 응답은 `{job}`·`{revision}`·`{asset}`처럼 감싸서 준다. **서명 URL 만료(정본): 업로드 15분·다운로드 10분.** 단, 사용자 업로드(A-10)는 Supabase `/object/upload/sign`이 만료를 지정할 수 없어 실측 **2시간**(응답 `expires_at`, 비공개 버킷·경로 고정·덮어쓰기 끔으로 수용, `tasks/task-022.md#구현 결정`). 워커 URL도 같은 규칙: 입력 다운로드(W-06, GET) 10분 · 산출물 업로드(W-07, PUT)는 같은 Supabase 제약으로 실측 **2시간**(응답 `expires_at`, `tasks/task-023.md#착수-결정` E7). 만료되면 워커가 다시 발급받는다.
