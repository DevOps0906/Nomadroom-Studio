## 1. 한 줄 정의
영상 제작 운영자가 YouTube 정체 후보를 자동 수집·두 시점 조회수로 판정해 제작 가능한 소재를 근거와 함께 고르게 하는 내부 대시보드.

## 6. 하지 않을 것 · 금지 문구
- 결제·다중 워크스페이스·외부 고객 제공을 하지 않는다.
- LLM은 제작 AI 초안(S8·S12)에서만 Claude로 호출한다. 수집·판정·후보 요약 등 그 외 기능에서는 LLM을 호출하지 않는다. 키는 FastAPI에만 둔다.
- "제작" 메뉴는 카테고리형·예능형 제작(`/production`) 화면만 내부로 만든다. 업로드와 나머지 메뉴(AI 작업방·소재보관함·주제 발굴·진단·채널 관리·배우기·설정)는 새로 만들지 않고 외부 링크만. MON-01 "영상 만들기 →"는 외부 운영 사이트 링크로 유지한다.
- 카테고리형 제작: P2(일본어)·후속(카테고리형 1080×1920·롱투숏·동시 렌더)은 하지 않는다. 로그인·쿠키·접근 제한을 우회해 원본을 받지 않는다. TTS·음성 실패 시 무음·가짜 음성으로 대체하지 않는다.
- 예능형 제작: CapCut 프로젝트는 읽지도 내보내지도 않는다(산출물은 MP4 + 리포트만, 결정 D-V4). 컷별 속도·J/L 컷·색 효과·별도 BGM·미리보기 영상은 하지 않는다. 받아쓰기 실패 시 가짜 자막으로 채우지 않고, 음성 파일은 PC 밖으로 보내지 않는다. 형식은 작업 생성 후 바꿀 수 없다.
- 조회수·라이선스·채널 정보를 vidIQ 화면 긁기에만 의존해 확정하지 않는다(근거 값은 YouTube Data API v3).
- C.C만 조건에서 라이선스 미확인을 "제작 가능"으로 표시하지 않는다(근거 대기, #9).
- 화면 문구는 "수익 보장", "100% 정확" 같은 단정 표현을 쓰지 않는다. 시간 표시는 한국 시간.
