## 1. 한 줄 정의
영상 제작 운영자가 YouTube 정체 후보를 자동 수집·두 시점 조회수로 판정해 제작 가능한 소재를 근거와 함께 고르게 하는 내부 대시보드.

## 5. 성공 지표 (목표는 가정 — `00_LEAN.md` 통과 기준과 동일)
| 지표 | 목표 | 측정 방법 |
|---|---|---|
| 소재 선정 시간 | 수동 대비 50% 이하 | 사용 전후 각 3건 이상 운영자 자가 기록 |
| 제작 전환 | 2주 내 1건 이상 | 사용한 소재 표시 수(A-08, `candidates.used`) + 운영자 확인. 클릭 로그 테이블은 만들지 않음 |
| 판정 신뢰도 | 표본 10건 중 80% 이상 맞음 | 관측 근거를 YouTube 화면과 대조 |
| 후보 가져오기 성공률 | 80% 이상 | 워커 실행 로그의 성공/실패 집계 |
| API 할당량 사용 | 예상 사용률 ≤50%(목표) | Google Cloud 콘솔 사용량(Q3). 운영 방어선 80%(초과 시 수집 중지)는 `adr/0002-observation-quota.md` |

## 6. 하지 않을 것 · 금지 문구
- MVP에서 LLM 호출·결제·다중 워크스페이스·외부 고객 제공을 하지 않는다.
- 나머지 메뉴(AI 작업방·소재보관함·주제 발굴·제작·업로드·진단·채널 관리·배우기·설정)를 새로 만들지 않는다. 외부 링크만.
- 조회수·라이선스·채널 정보를 vidIQ 화면 긁기에만 의존해 확정하지 않는다(근거 값은 YouTube Data API v3).
- C.C만 조건에서 라이선스 미확인을 "제작 가능"으로 표시하지 않는다(근거 대기, #9).
- 화면 문구는 "수익 보장", "100% 정확" 같은 단정 표현을 쓰지 않는다. 시간 표시는 한국 시간.

| 라이선스 예외 | 없음(Playwright 등 새 의존성은 `secscan license` 확인) |

| 항목 | 후보 가져오기·기록 검증 API (웹→FastAPI) | 로컬 워커 (Chrome·vidIQ) | 웹 (로그인·Route Handler·후보 화면) |
|---|---|---|---|
| 노출 면 | 인증된 사용자만 호출하는 API | 외부 노출 없음(아웃바운드: FastAPI `/worker/v1/*`·vidIQ) | 인터넷 공개 `/login`, 로그인 후 Route Handler·화면 |
| 인증·인가 | Supabase 세션 필수 · 같은 워크스페이스만 · RLS | 워커 토큰으로 `/worker/v1/*`만 호출. DB 직접 접속 없음(`adr/0001-worker-location.md`) | Supabase Auth, 계정은 관리자 초대만. 로그인 시도 제한은 웹 서버의 접속 IP별 제한(1차) + Supabase Auth 기본 제한(2차)(사용자 결정 2026-11-16) |
| 다루는 데이터 | 조건·후보·관측값(공개 데이터) | vidIQ 로그인 세션(쿠키) | 세션 쿠키(httpOnly), vidIQ 유래 제목·채널명·썸네일 URL |
| 필요한 키·권한 | YouTube API 키(서버 전용, 할당량 제한·API 제한 설정), service_role(서버만) | 워커 토큰만(해시로 저장, 워크스페이스 범위). service_role·DB 접속 정보 없음 | anon 키만(공개 가능) |
| 입력 | 조건 값 검증(Pydantic), 키워드·수치 범위 제한 | vidIQ 페이지 파싱 결과는 신뢰하지 않고 형식 검증 | vidIQ 유래 값은 비신뢰: 텍스트로 이스케이프해 렌더링(HTML 삽입 금지), 썸네일은 `i.ytimg.com` 허용 목록만 |
| 체인 | 키 노출 → 할당량 소진·서비스 중단 | PC 침해 → vidIQ 계정·워커 토큰 탈취 → 가짜 후보 주입 | 타 사이트 요청 위조 → 실행류·수정 API 오남용 |
| 피해 범위 | 해당 워크스페이스 데이터 + API 할당량 | vidIQ 계정, 자기 워크스페이스 큐·후보 쓰기(다른 워크스페이스 접근 불가) | 로그인 사용자 권한 범위 |

## 9. 판정 규칙 (프로필 p, 후보 c — 판정 정본)
| 순서 | 판정 | 조건 | reason 코드 |

| 1 | 조건 제외 | 키워드 미포함 | `keyword` |
| 2 | 근거 대기 | 이전 관측 없음 | `no_prev` |
