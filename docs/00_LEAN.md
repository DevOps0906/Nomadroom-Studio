# 00 린 검증 — Nomadroom Studio

> 내부 도구(1인·소규모 팀, 결제 없음)라 간단 검증: 실제 제작에서 효과를 측정한다. 근거: `01_PRD.md#3`(범위)·`#6`.

| 항목 | 내용 |
|---|---|
| 문제 | 영상 제작자가 소재(정체 후보)를 고를 때 vidIQ·YouTube를 수동으로 오가며 조회수·라이선스를 기록·비교한다. 시간이 들고 판단 근거(두 시점 조회수)가 남지 않는다. |
| 고객 | 내부 운영자 1~3명(채널 제작자). 외부 고객 없음 |
| 가설 | "운영자는 후보 자동 수집 + 두 시점 조회수 판정을 쓰면 소재 선정 시간을 절반 이하로 줄이고, 제작 가능 판정 후보를 실제 제작에 쓸 것이다" |
| 대안(경쟁) | ① 수동 vidIQ 검색 + 스프레드시트 ② 기존 운영 사이트의 소재수집(일반) ③ YouTube 직접 탐색 |
| 가장 싼 검증 | 노코드 대신 **MVP 직접 사용**: 로그인 + 소재수집(정체)만 만들어 운영자가 2주간 실제 제작에 사용 |
| 통과 기준 | 아래 표 (모두 가정 — 착수 전 운영자와 확정) |
| 기한·비용 | 사용 2주 · 추가 비용 0원(YouTube API 무료 할당량 + 기존 vidIQ 구독) |
| 결과 | (검증 후 기록) 통과 / 보류 / 폐기 + 근거 |

## 통과 기준 (가정)
| 지표 | 기준 | 측정 |
|---|---|---|
| 소재 선정 시간 | 수동 대비 50% 이하 | 사용 전 3건 수동 소요 시간 vs 사용 후 3건 이상, 운영자 자가 기록 |
| 제작 전환 | 제작 가능 후보 중 1건 이상 실제 영상 제작 | 사용한 소재 표시 수(A-08) + 운영자 확인 (`01_PRD.md#5`) |
| 판정 신뢰 | 운영자가 "근거 맞음" 응답 80% 이상 | 관측 근거 10건 표본 점검 |
| 수집 안정 | 후보 가져오기 성공률 80% 이상 | 실행 로그 성공/실패 집계 |

## 시장 관점 (1줄씩)
- 수익: 내부 도구 — 직접 수익 없음, 제작 시간 절감이 가치.
- 자동화: 수집·관측·판정 자동(핵심). 정부지원: 해당 낮음(미확인).
