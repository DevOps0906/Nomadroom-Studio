# 카테고리형 — 링크에서 완성 영상까지

## 목적과 기본값

사용자는 ZIP과 원본 영상 링크만 제공한다. 작업을 수행하는 AI가 설치·원본 확인·대본·JSON 작성·실행·검수를 담당한다. 사용자에게 코드를 직접 입력하거나 project.json을 작성하도록 떠넘기지 않는다. 한국어판 한 편을 기본으로 하며 일본어판이나 두 언어를 요청하면 별도 파일로 만든다. 사용자의 현재 요청이 기본값보다 우선한다.

이 패키지는 Python 실행, 패키지 설치, 네트워크, 이미지/영상 확인, 결과 파일 전달 기능이 있는 AI 환경용이다. 실행 도구가 없으면 파일만 읽은 것으로 영상 제작이 가능하다고 말하지 않는다. ZIP 첨부는 모델 재훈련이나 영구 설치를 뜻하지 않는다.

## 최초 준비

1. ZIP을 작업 폴더에 풀고 이 파일 및 [화면 규격](references/style.md)을 읽는다. 이 파일의 위치가 패키지 루트다.
2. 환경에서 Python 3.11 이상을 찾고 루트에서 `python bootstrap.py`를 실행한다. 시스템에서 명령이 `python3`라면 그것을 쓴다. 외부 설치가 제한되면 현재 환경에 있는 동등한 의존성을 활용할 수 있는지 확인한다.
3. 이후 아래 명령의 `PY`를 **실제 생성된 가상환경 Python 경로**로 바꾼다. Windows는 `.venv/Scripts/python.exe`, macOS/Linux는 `.venv/bin/python`이다. 경로에 공백이 있으면 인자 배열이나 셸의 올바른 따옴표를 쓴다.
4. `PY scripts/run.py doctor`가 성공하는지 확인한다. ffmpeg는 시스템에 있으면 사용하고 없으면 imageio-ffmpeg 패키지가 제공하는 실행 파일을 사용한다. 폰트는 ZIP 안에 들어 있다.

## 링크를 받으면 수행할 절차

1. `PY scripts/run.py prepare "영상_URL" --work "work/작품01"`을 실행한다. 로컬 영상 경로도 가능하다. 새 작품은 새 폴더를 사용한다. 긴 영상은 내용을 확인해 짧은 구간을 선택하고 `--start 30 --duration 18`처럼 지정한다. 선택된 원본을 `source.mp4`로 정규화하며 이후 타임라인은 모두 이 파일의 0초 기준이다.
2. `work/작품01/analysis.json`, `source.mp4`, **모든** `sheets/*.jpg`를 확인한다. 시트는 0.5초 간격이고 각 프레임 위에 시간이 적혀 있다. 경계 후보는 빠른 움직임도 포함하므로 실제 컷을 확인한다. 필요한 장면은 별도 프레임을 추출한다. 시트만으로 원본 대사 뜻이나 전체 동작을 확인했다고 주장하지 않는다.
3. 장면에 맞는 제목 2줄, 짧은 훅, 컷별 자막과 엔딩을 작성한다. [프로젝트 형식](references/project-format.md)에 따라 AI가 `project_ko.json`을 작성한다. 일본어판 요청 시 일본어로 의역한 `project_ja.json`을 별도로 만든다. 원본 내용·외국어 대사의 뜻을 확인할 수 없으면 추측을 사실로 적지 않는다.
4. `PY scripts/run.py render "work/작품01/project_ko.json"`을 실행한다. 첫 훅 음성 생성, 앞뒤 무음 제거, 원본 음량 조정, 제목·자막 합성과 MP4 저장이 이어진다. 훅이 첫 자막보다 길면 오류의 실제 길이를 참고해 훅을 줄이거나 첫 자막 구간을 조정하고 다시 실행한다.
5. 출력 MP4와 `.report.json`을 확인한다. 각 컷 프레임과 실제 재생으로 자막·핵심 피사체 잘림, 원본 라벨 노출, 글자 깨짐, 음성 누락, 훅 이후 원본 소리 복원을 점검한다. 검수 후 생성된 MP4를 사용자에게 파일로 전달한다. 검증하지 못한 항목은 짧게 밝힌다.

## 제작 규칙

- 소재는 제한하지 않는다. 원본 순서를 기본으로 유지하고 제목 2줄, 컷별 자막, 첫 훅 한 문장 음성을 추가한다.
- 기본 출력: 608×1080, 30fps, H.264/AAC. 상단 280px는 검정 제목 영역이다.
- 컷마다 자막 하나, 같은 시점에 두 자막 금지. 기본 표시 시간 1.4초 이상. 빠른 컷은 인접 컷을 하나의 자막 구간으로 묶어 읽을 시간을 확보한다.
- 흰 자막은 `~하고/~했는데/~더니`, 괄호는 장면 속 속마음, 초록 강조는 짧은 반응이다. 별표와 괄호는 문구에 직접 넣는다. 마지막은 `~다고 ..` / `~って…` 같은 여운을 남긴다.
- 얼굴뿐 아니라 손·악기·동물·제품 등 핵심 피사체와 동작을 보존한다. 배율·Y값은 샘플을 맹목적으로 복사하지 말고 실제 프레임에 맞춘다.
- 댓글·로고는 기본으로 추가하지 않는다. 필요한 출처 표기는 반영한다. 원본의 출처·권리자 워터마크를 일반 자막과 구분한다.
- 훅에만 음성, 나머지는 원본 소리. 원본 볼륨은 훅 구간 20%, 이후 100%. 원본에 소리가 없으면 훅 외 구간은 무음이다.

## 이 배포본의 음성·폰트

- 기본 음성: edge-tts 온라인 음성, 한국어 InJoon / 일본어 Nanami, 속도 +50%. API 키를 입력하지 않는다. 네트워크와 외부 서비스 가용성에 의존한다. 타입캐스트 진우·Miu와는 다른 음성이며 화남 감정을 동일하게 재현하지 않는다.
- 음성 서비스가 실패하면 한 번 재시도하고, 계속 실패하면 AI 환경의 실제 음성 생성 기능 또는 사용자가 제공한 음성을 `hook_audio`로 연결한다. 아무 말 없이 무음·가짜 음성으로 대체하지 않는다. 대안도 없으면 장애를 알리고 제작 상태를 보존한다.
- 한국어 제목: Pretendard Black. 한국어 자막: Noto Sans CJK KR Bold. 일본어 제목·자막: Noto Sans CJK JP Bold. 원본의 카페24·Yu Gothic·Microsoft Sans Serif는 배포본에서 대체했다. 라이선스는 `licenses/`에 있다.

## 실패 시 처리

- 다운로드가 차단된 링크는 성공했다고 꾸미지 않는다. 정상적인 공개 링크인지 확인하고, 지원 사이트 변경 문제라면 yt-dlp 공식 업데이트를 한 번 적용해 재시도할 수 있다. 로그인·접근 제한을 우회하거나 브라우저 쿠키를 자동 수집하지 않는다. 계속 실패하면 원본 영상 파일이 필요하다고 안내한다.
- 설치/코드 실행 기능이 없는 환경에서는 이 ZIP만으로 실행되지 않는다. 부족한 기능을 구체적으로 알린다.
- 결과 파일이 이미 있으면 새 이름을 사용한다. 의도적인 재렌더만 `--overwrite`를 사용한다.
- 이 스킬은 제작 권한만 다룬다. 게시·업로드·계정 결제는 별도 사용자 요청 없이 실행하지 않는다.
