# project.json — AI가 작성하는 편집 설정

모든 경로는 project.json이 있는 폴더 기준이다. 모든 시간은 prepare가 만든 source.mp4 기준 초 단위다. 원본 URL의 절대 시간과 섞지 않는다. JSON은 UTF-8이며 BOM도 허용한다.

```json
{
  "lang": "ko",
  "source": "source.mp4",
  "duration": 8.0,
  "output": "result_ko.mp4",
  "header": ["제목 첫째 줄", "제목 둘째 줄"],
  "hook": "이렇게 바뀐다는데?",
  "shots": [[0, 2, 1.0, 0], [2, 4, 1.15, -90], [4, 6, 1.3, -140], [6, 8, 1.0, 0]],
  "items": [[0, 2, "white", "이렇게 바뀐다는데?"], [2, 4, "paren", "(이게 된다고?)"], [4, 6, "emph", "*이렇게 완성*"], [6, 8, "white", "마지막까지 이어진다고 .."]]
}
```

위 문구와 컷 경계는 **형식 예시**다. 실제 원본에 맞게 새로 작성한다.

- `lang`: `ko` 또는 `ja`.
- `duration`: analysis.json의 길이 이하, 최대 180초. 실제 출력은 1/30초 단위로 올림한다.
- `header`: 줄바꿈 없는 제목 문자열 정확히 2개. 폭을 넘으면 자동 축소한다. 너무 길면 오류를 내므로 짧게 다시 쓴다.
- `hook`: 첫 문장 음성용 텍스트. 첫 자막과 뜻이 같아야 한다. 한글/일본어 기본 음성이 자동 선택된다.
- `shots`: `[시작, 끝, 배율, Y]`. 0초부터 duration까지 빠짐없이 이어져야 한다. 배율 1~3, `Y≤280`, `Y+1080×배율≥1080`. 얼굴이나 피사체가 잘리지 않는지 프레임을 확인한다.
- `items`: `[시작, 끝, 종류, 문구]`, 또는 마지막에 자막 중심 Y를 추가한다. 종류는 `white`, `paren`, `emph`. 시간 순서대로 작성하고 겹치지 않는다. 별표·괄호는 자동 삽입하지 않는다. 첫 자막은 0초부터 시작한다. 훅 음성 길이 +0.08초가 첫 자막 안에 들어와야 한다.
- `hook_audio`: 선택. 직접 만든 훅 녹음/AI 음성 경로. 지정하면 온라인 TTS를 건너뛰고 무음 정리만 한다. 이 경우 원본 녹음 속도를 유지한다.
- `voice`: 선택. edge-tts의 실제 음성 이름. `rate`: 선택, 기본 `+50%`.

원본이 9:16이 아니면 우선 608×1080을 채우도록 비율 유지 확대 후 중앙 크롭한다. `shots`의 좌표는 이 변환 이후를 기준으로 한다. 가로 영상은 중요한 부분이 잘릴 수 있으므로 준비 단계에서 해당 구간의 구도를 확인하고 필요한 경우 별도로 세로 구도를 만든 후 사용한다.

출력은 MP4, 실제 훅 WAV, 측정 결과 `.report.json`이다. 훅 종료 시각은 음성에서 자동 계산되므로 기존 인수인계 문서의 `hook_end` 필드는 사용하지 않는다.
