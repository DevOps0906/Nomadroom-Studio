# 예능형 실습 CapCut 프로젝트 분석 (근거 자료)

> 출처: 사용자 제공 ZIP `1-2. 예능형 실습 캡컷 프로젝트 파일 + 미디어 파일.zip`(2026-11-19, 약 34.6MB). 팀장이 `draft_content.json`과 완성본 MP4를 직접 분석했다. 기획 정본은 `docs/01_PRD.md`의 예능형 제작 행이고, 이 문서는 근거로만 쓴다. ZIP·영상은 저장소에 넣지 않는다(제3자 채널 영상 포함).

**핵심**: 예능형은 카테고리형과 다르다. 카테고리형은 원테이크를 시간순으로 재생하면서 구도만 바꾼다. 예능형은 원본 대화에서 **컷을 골라 순서를 바꿔 이어 붙인다**(재배치). 화면은 흰 캔버스 위에 영상 띠를 두고, 고정 제목·대사 자막·반응 자막을 얹는다. 따라서 편집안 스키마와 렌더러를 따로 만들어야 한다. 원본 준비(prepare), 상태, 승인, 렌더 큐, 서명 URL, 검수는 카테고리형 것을 그대로 쓴다.

## 1. ZIP 구성
| 구성 | 파일 | 역할 |
|---|---|---|
| 미디어 | `예능형 미디어파일/[티티 스튜디오(TT STUDIO)] 관상을 보면 바람기를 알 수 있다？ (zvHFohZMi8g).mp4` | 원본. 1080×1920, 29.97fps, H.264/AAC, 51.5초. 원본에도 제목·자막이 박혀 있다(제3자 채널) |
| 미디어 | `예능형 미디어파일/실습(예능형).mp4` | 완성본. 1080×1920, 30fps, H.264/AAC, 24.75초 |
| CapCut 프로젝트 | `예능형 캡컷파일/draft_content.json`(+`.bak`·`template-2.tmp` 같은 내용), `Timelines/…/draft_content.json` | 타임라인 정본. 캔버스 1080×1920, 30fps, 길이 24.733초 |
| CapCut 부속 | `draft_meta_info.json`·`attachment_*.json`·`draft.extra`·`key_value.json` 등 | 작성자 PC 절대 경로(`C:/Users/o/...`), 캐시 소재 경로. 렌더에 쓰지 않는다 |

CapCut 형식은 비공개이고 PC 경로가 박혀 있다. Nomadroom은 이 형식을 읽거나 쓰지 않는다(D-V4). 구조를 이해하는 참고 자료로만 쓴다.

## 2. 타임라인 (완성본 기준)
| 트랙 | 개수 | 내용 |
|---|---|---|
| 영상(주) | 컷 14개 | 같은 원본에서 원본 시각을 골라 이어 붙임. 순서 재배치 있음 |
| 영상(가림) | 2개, 전체 길이 | 흰 이미지 2장(위 y=+0.74, 아래 y=−0.75). 원본에 박힌 제목·자막을 가린다 |
| 텍스트(대사 자막) | 19개 | 알약 모양 자막. 검정 바탕+흰 글자(size 10). 펀치라인 3개는 빨강 바탕(size 12) |
| 텍스트(반응 자막) | 4개 | "(나는 왜?)" "(긴장...)" "(다행이다..)" "하...핳하ㅏㅏ핳;;;;". 빨강 글자+흰 테두리, 위치 자유(x −0.48~+0.60), 대사 자막과 **동시 표시** |
| 텍스트(제목) | 1개, 전체 길이 | "끼는 넘치는데 / 바람은 못 피우는 사주ㅋㅋ" 2줄. 빨강 글자+흰 테두리, 잘난체 |
| 오디오 | 12개 | 원본 소리(`video_original_sound`). 컷과 거의 같은 원본 구간. 일부는 다음 컷 경계를 넘어 이어짐(J/L 컷 성격: 7.33초+2.83초, 16.00초+1.47초) |
| 효과 | 1개 | 채도(saturation) — 사용 범위 불명. 지원하지 않는다 |

- x·y는 CapCut 정규화 좌표(캔버스 중심 0, 가장자리 ±1). 배율 1.48은 원본 1080 폭 기준으로 화면 띠를 가득 채우는 값이다. x 이동은 말하는 사람을 띠 중앙에 맞추는 리프레임이다.
- 원본 구간이 겹쳐도(컷 1과 7) 된다. 출력 타임라인은 컷 길이의 누적이다.

## 6. Nomadroom 적용 메모
- 원본 준비(prepare: 구간 추출·analysis·시트)는 그대로 재사용한다. 원본 구간(최대 180초) 안에서 컷을 고른다.
- 편집안은 형식별 스키마로 나눈다(`format`=`category`·`variety`). 서버 검증 정본은 Pydantic이다.
- 렌더는 같은 로컬 워커가 맡고, 예능형 렌더 모듈만 새로 만든다. 순서는 컷별 trim → 띠 크롭·배율·x/y → 흰 캔버스 합성 → 제목·자막 PNG 오버레이 → concat → 음량 정규화 → MP4·리포트.
- 지원하지 않는 것: 컷별 속도 변경(예제 0.95 1건), 오디오 J/L 컷(소리는 컷 경계에서 자름), 채도 등 색 효과, CapCut 프로젝트 내보내기.
- 권리: 예제 원본은 제3자 채널 영상이다. 카테고리형과 같은 권리 확인(`rights_confirmed`·`credit`)을 적용한다.
