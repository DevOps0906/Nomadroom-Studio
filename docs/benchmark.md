# 벤치마킹 — 핵심 화면: 소재수집(정체) (MON-01)

> 형식: ux-patterns 3절. 비슷한 제품 3개 · 핵심 화면 1개. 이번 작성은 외부 접속·스크린샷 수집 없이 공개 제품 소개 기준의 기억으로 적었다. 모든 항목은 `미확인`이며 사람이 실제 화면을 열어 확인·스크린샷(`docs/benchmark/`)을 채운 뒤 확정한다.

| 제품 | 화면 | 반드시 있는 것 | 우리에게 없는 것 | 채택 여부 | 근거(URL·스크린샷 경로) |
|---|---|---|---|---|---|
| vidIQ (Outliers · Trending) | 평소보다 잘 나오는 영상 목록 | 썸네일·제목 카드, 조회수 대비 성과 배수 지표, 카테고리·기간 필터 (미확인) | 채널 평균 대비 배수 지표 | 일부 채택: 카드에 증가율 + 정렬(증가율·조회수·최신). 배수는 보류 | https://vidiq.com (스크린샷 미수집) |
| 1of10 | 아웃라이어 영상 탐색 | 썸네일 그리드, 키워드 검색, 형식(쇼츠/롱폼)·기간 필터 (미확인) | 저장된 보기(검색·필터 조합) | 채택: MON-01 `search`, 형식 필터 (저장된 보기는 이후, `01_PRD.md#3`) | https://1of10.com (스크린샷 미수집) |
| Viewstats | 영상·채널 조회수 추이 | 조회수 시계열 미니 차트, 기간 선택, 증가량 표시 (미확인) | 판정 사유를 근거와 함께 보여주는 상세 | 채택: 후보 카드 두 시점 미니 차트, MON-D2에 판정 사유·두 시점 표 | https://viewstats.com (스크린샷 미수집) |

## 화면 표 반영 (MON-01 · MON-D2 `구성`)
- sort:증가율·조회수·최신 · search:제목·채널 · 카드의 미니 차트 · MON-D2 `text:판정 사유`.
- 채택하지 않음: 성과 배수(채널 평균 필요 — API 할당량 부담, `01_PRD.md#7` Q3), 추천 알고리즘.
- 확인 필요: 위 "반드시 있는 것"은 모두 `미확인`. 화면 확인 후 열 값과 채택 여부를 고친다.
