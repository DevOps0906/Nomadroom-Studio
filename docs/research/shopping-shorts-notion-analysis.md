# 쇼핑쇼츠(제휴 수익형) 노션 강의 분석

> 라벨: [강의]=노션 이미지/텍스트에서 읽은 주장, [웹]=웹 출처 확인, [추정]=내 해석. 이미지 출처는 "노션 이미지 #절".
> 링밥은 강의 강사 닉네임(슬라이드 "강사 링밥")이자 강의의 AI 제작 도구·제작형 이름이다. 상품·제휴처가 아니다(4장 "도구"에서만 다룬다).

## 1. 출처·읽은 범위
- 출처: 노션 페이지 "[디하클]폰편집으로 월9천 쿠팡 탑시크릿[링밥]"(2026-11-18 강의, Zoom 슬라이드 캡처 중심). 본문 텍스트는 전부 읽음.
- 페이지 이미지는 약 200장(캡처 PNG). **직접 열어 본 것은 74장**: 1차 49장 + 여행 절(실습3·쇼핑과 여행의 차이점) 22장 전부 + AI 영상 요금 3장(2026-11-19 추가분). 나머지는 서명 URL 용량·시간 제약으로 못 읽음.
- 읽은 구간: 도입 포스터, 업로드 시간대, 짤템 계정 화면, 인스타 알고리즘·관계지수·30만 건 분석, 재탕, 영드 vs 쇼핑 비교, 좋은 소재 4유형, 설득·후킹 9가지(6개 확인), 편집 BEST4, 건기식 금지, 실습1·2 일부, 실습3 여행·차이점 22장 전부(7장), AI 영상 요금 3장(7-6), 일본 수익 구조.
- **못 읽은 것**: 날먹형·정통형·링밥닷컴형 실습 화면, 링밥·인포크링크 조작 화면(링크 메뉴 1장만 간접), 어그로 소재찾기 1·2번 화면, 실습1 후반 편집 과정, 일본 TTS·자막 화면 일부, 하이라이트 후킹 9가지 중 이성적 설득 3종, 업로드 시간 후속 장. 이 장들의 내용은 본 문서에 "미확인"으로 표시한다.
- 상단 프롬프트(쇼핑 쇼츠 대본 작가, 텍스트)는 전문을 읽음: 3장에 반영.

## 2. 일반쇼츠 vs 쇼핑쇼츠
| 항목 | 일반(영드·해짜) 쇼츠 | 쇼핑쇼츠 |
|---|---|---|
| 수익 | 조회수 수익 [강의: "서로 수익 구조가 다름", 노션 이미지 #영드vs쇼핑] | 제휴 구매 수수료 [강의] |
| 성공 기준 | 시청에서 끝남 | 시청 -> 댓글 -> DM 확인 -> 링크 열기 -> 구매까지 CTA가 동작해야 함 [강의, #영드vs쇼핑 흐름도] |
| 핵심 | 몰입·완주 | "설득을 통한 행동유도"(이성적 설득=실용템 / 본능적 설득=신박템·어그로) [강의, #설득] |
| 링크 | 불필요 | 영상에 링크 직접 안 걸고 댓글->DM->인포크링크->쿠팡 [강의, #영드vs쇼핑] |
| 소재 | 재미·정보 | 아이템 자체가 구매 욕구를 줘야 함. 소재가 애매하면 입을 많이 털어야 CTA가 돈다 [강의, #소재] |
| 성별 | 무관 | 여성 타깃(30~40대) 전환율 좋음, 남성 타깃은 조회수는 좋으나 전환 낮음 [강의, #타깃] |

## 3. 쇼핑쇼츠 영상 구성
- 길이 15~20초, 대본 4문장(5번 없음), 공백 포함 110~140자 [강의, 상단 프롬프트 텍스트].
- 문장 구조 [강의, 프롬프트]: 1 후킹(제품명 말하지 않고 숫자·뜻밖의 결과·공감 불편 중 하나) / 2 불편을 겪던 상황 / 3 써 보니 달라진 장면(화면에 있는 것만) / 4 마무리 + 짧은 댓글 유도 한 마디. 소구점은 1개.
- 말투: 직접 써 본 사람이 친구에게 말하듯("~더라고요"). 광고 문구("강력 추천","인생템","지금 바로") 금지. 수치·가격은 제공 정보만, 지어낸 값은 [확인 필요]. 의약품·건강 효능·과장 금지. 출력: 후킹 다른 대본 3개 + 글자 수·후킹 방식 + 업로드 전 확인 사실 목록.
- 장면 순서(권장 구조) [추정, 위 4문장에 장면 1:1 매핑]: 0~3초 후킹 화면 / 3~8초 불편 상황 / 8~15초 사용 전후 / 15~20초 CTA 자막.
- 편집 BEST 4 [강의, #신뢰 편집]: 자막(중국어 등 외국어 자막은 삭제 가능하면 삭제, 아니면 모자이크), TTS는 기계음 티 나지 않게, 대본-영상 싱크(리듬·속도), 친구한테 말하듯.
- 신뢰 이론 [강의, #신뢰]: 사람들은 출처보다 이야기·정보에 집중, 1인칭 서사가 공감, 광고 방어심리를 낮춤. 구라인 줄 알아도 팁이 있으면 OK.
- BGM·화면 텍스트·고정댓글 문구: 이미지 미확인. CTA 자막 예: 영상 하단 "확인하세요" 계열 텍스트가 보임 [강의, #편집을 두려워 마세요 4개월 후 비교]. 고정댓글/링크 문구 구체 예시는 **미확인**.
- 구조 벤치마킹 [강의]: 단어만 바꾸지 말고 구조(비일상 시작 -> 궁금증)를 따라한다. 같은 소재 대본을 그대로 가져오면 어문저작권 침해 -> 저작권 스트라이크 위험.
- 후킹 9가지 중 본능적 설득 6종 [강의, #후킹 9가지]: 손실 회피, 정체성 자극, 궁금증 유발, 희소성, 감정 공감, B급 유머.

## 4. 제작 유형과 도구
- 강의 제목·부제: 날먹형·정통형·링밥닷컴형 영상 제작 실습 [강의, 페이지 도입 박스]. 세 유형의 차이 화면은 **미확인**. [추정] 날먹형=원본 영상에 자막·TTS만 교체, 정통형=직접 편집·촬영, 링밥닷컴형=AI 도구로 대본·편집 자동화.
- 도구(링밥 포함) [강의]: 링밥(AI 제작) -> 인포크링크(프로필 링크 페이지) 연결 [페이지 최상단 박스]. 인스타 프로필의 link.inpock.co.kr 링크가 쇼핑 계정 예시(zzal.tem) [노션 이미지 #짤템].
- 그 외: CapCut(캡컷) 편집 "하루 컷 가능, 50대 어머니도"; 첫 숙제 vs 4개월 후 비교 [노션 이미지 #편집 두려움]; Codex(ChatGPT)로 중국어 검색어 찾기, 영상 분석, 일본어 구어체 변환 [노션 이미지 #실습1, #실습2]; Canva 강의 자료 제작 화면.
- 시장 맥락 [강의, #Hoxy 레드오션]: SNS 커머스 시장 23년 28조 -> 24년 35조 -> 27년 50조 예상(출처 표기 불명, 근거 약함).

## 5. 소재·제품 선정
- 좋은 소재 4유형 [강의, #좋은 소재]: 1 비주얼 후킹(예쁜 쓰레기) 2 미친 가성비 3 신박한 기능 4 기타 어그로.
- 내 눈 기준 금지: "내 시각을 보편화하는 게 가장 위험", "여러분 감의 반대로 하는 게 더 확률 높다" [강의, #잘 팔리는 제품]. 진짜 팔릴지는 "AI 판단" 데이터로(슬라이드 "Alppano"로 보이나 판독 불확실) [강의, 불확실].
- 판단 질문: 어그로가 끌리는가, 시장에서 먹히는가, 발걸음을 멈추고 보는가 [강의].
- 소재 찾기 2번 = "터진 소재를 찾는다" [강의, 페이지 소제목]. 데이터 기준 수치(조회수 임계 등)는 **미확인**.
- 타깃 [강의]: 여성 상품 카테고리. 쇼핑 예시 계정 영상 조회수는 수백~2천대 [노션 이미지 #짤템 릴스].
- 금지 [강의, #건기식]: 의약품·건기식은 절대 불가("우리는 광고대행업, 법적으로 광고 자체가 문제 있으면 X"). 식약처 건강기능식품 인증 마크 슬라이드.
- 미확인: 카테고리 목록·남성용 허용 범위.

## 6. 원본 확보·편집·저작권
- 절차 [강의, #실습1]: 샤오홍슈(rednote.com) 접속 -> 아이템 탐색 -> 영상 다운로드 -> Codex로 중국어 검색어·영상 분석 -> 편집(자막 교체·TTS). 틱톡 "Iron Man 이어폰" 영상도 사용 예.
- 강의 주장: "저작권 위험부담을 줄이기 위해 최소 3개 이상 영상을 다운받아라" [강의, 노션 텍스트]. **이는 법적 근거가 없는 주장이다**. 여러 개를 섞어도 각 원본의 복제·2차적저작물 이용이면 침해가 될 수 있다 [추정, 12장 근거 참조]. 제품 사진·영상은 판매·제조사가 제공한 소재를 쓰는 편이 안전하다 [추정].

## 7. 여행 쇼핑쇼츠 (실습3 + 쇼핑과 여행의 차이점)
읽은 범위: 실습3 11장 + "쇼핑과 여행의 차이점" 11장 = 22/22장 전부 열어 봄(2026-11-19 캡처). 출처 표기 "[노션 이미지 #실습3-n]"(n=절 안 순서), "[#차이-n]". 본문 박스 "3가지 패턴 모두 댓글을 남기게 하는 것"은 텍스트로 읽음. 마무리 추가분(2026-11-19 재확인): 노션 페이지 끝까지 확인, 마지막 이미지는 04_01_55(검수 기준). 03_53_14 이후 이미지 5장(03_56_07, 03_58_58, 04_00_24, 04_00_42, 04_01_55)을 7-8에 정리, 03_47_40은 다시 열어 "① 비용이 좀 들어요"(사진 -> AI 영상 생성(구독) -> 편집)임을 확인. 출처 표기 "[노션 이미지 #마무리-n]".

### 7-1. 차이점과 비슷한 점
- 비슷한 점(=본질) [#실습3-10,11]: 타깃(간접 구매) / 카테고리(좋아하는 것) / 설득(소구점으로) / 행동 유도(CTA 돌리기) 4칸이 쇼핑=여행. "본질 = 설득을 통한 행동 유도(CTA), 똑같아요". 박스: 목적은 댓글을 남기게 하는 것 [강의 박스].
- 다른 점은 영상 출처 하나 [#차이-1]: 쇼핑=소재 찾기 -> 영상 퍼 오기(샤오홍슈·틱톡) -> 대본 -> 음성(TTS) -> 편집 / 여행=소재 찾기 -> 사진 + AI 영상 -> 대본 -> TTS -> 편집. "영상을 AI로 만들어요" [#실습3-1, #차이-1].
- 여행이 쉬운 이유 [#실습3-4,9, #차이-6]: 제휴처 많음 / 단가 큼 / 공유·저장 많음 / 난이도 쉬움(릴스 인사이트 조회 100만대 3건 예시, "대본·퀄리티가 조금 부족해도 볼 사람은 봐요") [#실습3-9].

### 7-2. 제품 vs 여행
| 항목 | 제품(쇼핑) | 여행 |
|---|---|---|
| 파는 것 | 물건 | 숙소·투어·패키지(경험·장소). 항목마다 제휴처가 따로 [#실습3-2] |
| 단가 | 상대적 작음 | 큼. "1개만 팔려도 이득", 보통 1박만 하지 않음. 이미지의 제주 호텔 목록은 1박 약 6.8만~52만원대 [#실습3-4]. 강의: 우리는 간접 수수료라 직접 판매 비중은 크지 않으나 가전 판매 수수료 수준 |
| 구매 주기·결정 | 즉흥 구매 가능(후킹 15~20초) | 정보 찾기가 귀찮은 과정, 대신 골라 추천 -> 좋은 숙소 발견 [#차이-7,8]. 저장·공유되는 "저장형·정보성 콘텐츠"(육아·여행·교육·경제·재테크) [#차이-9] |
| 수수료 구조 | 제휴 구매 수수료 | 숙소 수수료 구조는 이미지 미확인 |
- 구매 주기(재구매 간격)·결정 기간 숫자는 이미지에 없음: **미확인**.

### 7-3. 광고 vs 설렘
- 강의 표현은 "셀럽"이 아니라 **"설렘"**: 슬라이드 "왜? 여행은 광고가 아니라 설렘이라서" [#차이-4, 판독 확실]. 제품=광고로 느껴져요 / 여행=설렘으로 느껴져요.
- 근거 흐름 [#차이-2~5]: 쇼핑 콘텐츠=제품 광고, 우리는 광고를 거의 안 봄 -> 그런데 홈쇼핑 여행 패키지(NS홈쇼핑 중앙아시아·싱가포르·장가계)는 "이건 봐요!" -> 홈쇼핑에서도 여행은 효자(2천만원대 남미 패키지 방송 70분 목표 대비 16배(2025), 540만원대 크루즈 10개월 순매출 215억(2023), 뷰티·패션·여행 고마진 상품군(2024)). 수치는 강의 슬라이드 주장이며 출처 미표기.
- 셀럽·인플루언서가 경험을 보여 주는 서사라는 내용은 이미지에 **없음(미확인)**. 위 해석은 "광고 방어심리가 낮은 정보·설렘형"으로만 확정.

### 7-4. 스토리텔링 구성·3패턴
- 대비를 스토리로: 귀찮은 정보 찾기 -> 우리가 골라서 추천 -> 좋은 숙소 발견, 시청자는 보기만 하면 됨 [#차이-8]. 사진 고르는 기준 5개: 공식 사진·영상만 / 남이 찍은 사진 X / 블로그·이미지 검색 퍼 오기 X / 대표 시설(스파·수영장·외관)이 잘 보이는 사진 / 나만의 해석(대본·장면 고르기·편집) [#실습3-8].
- **3가지 패턴의 이름·장면 흐름·대본 문장 구조·후킹·댓글 유도 문구는 이미지에 없음: 미확인.** 박스는 "3가지 패턴 모두 댓글 유도"만 말함. 쇼핑 4문장 구조(3장)를 여행에 적용하는 것은 [추정].

### 7-5. 영상 생성 방식
- 입력은 사진: "사진 -> AI 영상 생성(구독) -> 편집" [#차이-10]. 예시 사진은 산 전망 객실 노천 스파. 프롬프트 문구, 장면 수·길이, 해상도는 이미지 미확인. 길이는 쇼핑 15~20초(3장)를 따른다고 [추정].

## 9. 업로드·운영
- 시간대 [강의, 노션 텍스트 + #업로드 시간]: 유튜브는 시간대 무관, 인스타는 중요. 원래는 계정마다 다르나(팔로워 활동 시간 1~2시간 전), 쇼핑은 24시간 쿠키 고려해 **오전 8시 발행 기본, 오후 6시 옵션**. 1일 1릴스=오전 8시 / 1일 2릴스=오전 8시+오후 6시. 인사이트 화면에서 여성 65.7%, 35~44세 46.6%.
- 초반 지표 [강의]: 인스타 초반 100단위가 정상 / 유튜브 초반 1000단위가 정상.
- 알고리즘 [강의, #인스타 관계지수]: 인스타는 계정 간 친밀도(관계지수) 기반으로 팔로워 -> 관심사 -> 관계망 순으로 노출(Small Batch Test). 인스타그램피셜+30만 건 분석: 최근 9~12개 게시물이 기준(오차 5~20) [강의, 주장]. 인스타 로고 히스토리(2010 Burbn 등) 슬라이드.
- 재탕 [강의, #개꿀]: 인스타는 과거 영상을 100% 동일하게 재업로드해도 지속 노출 가능, 대본·섬네일·편집 다시 안 함. 터진 콘텐츠가 쌓일수록 난이도 낮아짐. 같은 영상 반복 업로드 예 조회수 16.9만 / 124.6만 / 6만 / 63.8만. 유튜브는 재사용 콘텐츠 정책이 별도로 있어 같은 방식이 위험하다 [웹 확인 한계: https://vidiq.com/blog/post/youtube-reused-content-policy-guide/].
- 다계정·프리랜서 협업: 소개글에 있으나 화면 미확인.
- 짤템 계정(zzal.tem) 사례: 게시물 25개, 팔로워 816, 릴스 조회수 600~2,500대 [노션 이미지 #짤템].
